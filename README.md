# Maison de l’Inde — Site vitrine

Bienvenue sur le dépôt officiel du site vitrine du restaurant **Maison de l’Inde**, situé à Saint-Louis (68300).  
Ce site présente notre cuisine indienne et kashmiri, nos horaires, notre carte complète, et propose un menu téléchargeable en PDF.

---

## 📦 Structure du projet

maison-de-linde/
├── index.html                    → Page principale du site
├── style.css                      → Feuille de style principale
├── script.js                      → Interactions (popup, slider, PDF, etc.)
├── menu.pdf                        → Menu téléchargeable
├── CNAME               → Lien vers le domaine lamaisondelinde.fr
├── README.md                      → Ce fichier
└── assets/             → Images, SVG, favicon, etc.

## 🧰 Fonctionnalités

- **Bannière livraison** fixe en haut de page
- **Popup d’annonce** avec horaires et rayon de livraison
- **Présentation du restaurant** avec texte d’accueil
- **Carte complète** avec tous les plats, prix et catégories
- **Menu PDF** téléchargeable et affiché en aperçu
- **Section contact** avec adresse, téléphone, horaires et lien Instagram
- **Design responsive** adapté aux mobiles
- **Slider photo** en haut de page (si activé)

---

## 📄 Modifier le menu

Pour mettre à jour la carte :

1. Modifier le contenu dans `index.html` (section `#menuSection`)
2. Mettre à jour le fichier `menu.pdf` dans la racine si besoin
3. Commit avec un message clair, par exemple :  
   `update: ajout de nouveaux plats dans la carte`

---

## 🖼️ Ajouter des images

Les images du slider et du fond se trouvent dans le dossier `assets/`.  
Tu peux ajouter ou remplacer des fichiers comme :

- `taj1.jpg`, `taj2.jpg`, etc. → slider photo  
- `kashmir-floral.svg` → motif de fond  
- `tajmahal.svg` → illustration décorative  
- `favicon.ico` → icône du site
